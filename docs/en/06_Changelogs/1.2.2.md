Title: Release 1.2.2
Date: 2025-12-03 10:00
Category: changelog
Summary: Fluent and Subsite support and stability changes
---

### Features

- SDK support for the [Fluent](https://github.com/silverstripe/silverstripe-fluent) and [Subsites](https://github.com/silverstripe/silverstripe-subsites) modules in Silverstripe 6. 
  - These are available as separate modules that can be installed alongside the core search SDK.
  - The [Forager](https://github.com/silverstripeltd/silverstripe-forager/) module has also included some deprecations for `RemoveDataObjectJob` in favour of more aligned indexing job experience. This will become the new behaviour for indexing jobs in future releases.

### Changes

- Add documentation and search UI templating fix for the CMS 6 for `Record::getDecoratedLink()` which now requires an explicit string argument.
- Security and stability fixes
