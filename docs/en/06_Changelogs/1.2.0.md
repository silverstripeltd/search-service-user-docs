### Features

- Silverstripe CMS 6 is now supported by all core modules. Refer to the [SDK](https://github.com/silverstripeltd/silverstripe-search-sdk) for a list of all the modules.
    - The [Forager](https://github.com/silverstripeltd/silverstripe-forager/) module has had some major updates to simplify indexing logic. Refer to the [detailed migration notes](https://github.com/silverstripeltd/silverstripe-forager/blob/main/docs/en/12_v2_migration.md) for more information.
    - Subsites has been split to a [separate module](https://github.com/silverstripeltd/silverstripe-forager-subsites/) and is in an alpha state. Subsites is not considered part of the core feature set so support will be tracked in this module going forwards.

### Bugfixes

-   Correct pagination limits to match those documented on the [Limits and requirements page]({filename}/pages/limits-and-requirements.md)
-   Security fixes
