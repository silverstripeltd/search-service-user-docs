---
title: Dedicated tenancy
---

> [!NOTE]
> Features on this page are only supported on plans with Dedicated Tenancy features. For more information, refer to [Features](/features)


A single, dedicated tenancy improves the performance of your search by providing you with dedicated computational resources isolated from other tenants.

Please note single tenancy does not explicitly provide any additional security guarantees. Only computational resources will be isolated, other subsystems will still be shared.

If you require additional isolation please contact us via the [Silverstripe Cloud portal](https://silverstripe.cloud/) to discuss options.
