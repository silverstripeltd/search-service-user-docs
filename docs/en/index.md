# Silverstripe Search user guides
This site is a user-focused reference targeted at editors and administrators who create and manage Silverstripe Search.

This guide applies to version 1.x of the Silverstripe Search Service

- Setup Silverstripe Search for your website using our guide for [Getting started](/getting_started)
- Understand the capabilities of Silverstripe Search by learning its [Features](/features)
- For developers and implementing Silverstripe Search, use the [Developer’s guide](/developers-guide)
- Security resources are available in our [Security guide](/security_guide)
- Find answers to common questions in our [FAQ - Frequently asked questions](/faq)
- Check out changes to the service in our [changelog](/changelogs)
